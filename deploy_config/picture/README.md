# Estrutura de Imagens do Projeto

Este diretório contém as imagens exibidas no carrossel e nos cards do portfólio (`NiuanPortifolio`).

### Padrão de Nomenclatura:
- **`0.png`**: Capa principal do projeto (Screenshot da Home / Vitrine de Animais e Produtos). Usada como capa no card do portfólio e 1º slide do carrossel.
- **`1.png`**: Tela 2 do site em execução (ex: Catálogo de Animais para adoção/venda).
- **`2.png`**: Tela 3 do site em execução (ex: Catálogo de Produtos e Rações).
- **`3.png`**: Tela 4 do site em execução (ex: Agendamento de Serviços Veterinários e Banho/Tosa).
- **`4.png`**: Tela 5 do site em execução (ex: Carrinho de Compras / Autenticação).

> Certifique-se de que a quantidade de imagens corresponda ao campo `"imagesCount"` no arquivo `../config.json`.
